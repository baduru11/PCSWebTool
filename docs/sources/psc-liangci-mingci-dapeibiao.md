# 普通话水平测试用普通话常见量词、名词搭配表（参照复录）

- **What this is**: the official PSC appendix table of 45 common measure words and
  their sanctioned noun collocations（《普通话水平测试实施纲要》附录，选择判断
  量词、名词搭配项的评分依据）. A noun listed with a parenthetical, e.g. 狗（隻）,
  is officially acceptable under both measure words; the paired row cross-lists it
  reciprocally.
- **Source of this reproduction**: 北京普通話學會,
  <https://www.beijingputonghua.com/psc/liangci/liang.htm> (retrieved 2026-08-28,
  traditional-character rendering preserved verbatim below). Corroborated by
  independent search-index snippets reproducing the 把 and 根 rows verbatim, and by
  HKUST CLE's published test structure (<https://cle.hkust.edu.hk/tests/psc/psc/rules>).
- **Authority note**: this is a reference reproduction, not the printed 实施纲要
  (p.364). Before treating a row as final for teacher-facing decisions, spot-check
  against a print copy when one is available. Used as the runtime basis for C3
  measure-word `acceptedAnswers` (see PSC_C3_TEACHER_REVIEW_PACKET.md).
